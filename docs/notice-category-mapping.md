# 공고 카테고리 통합 매핑

기업마당과 K-Startup은 공고를 서로 다른 분류 체계로 나눈다. 두 원본 체계를 하나의 통합 카테고리로 매핑해, 수집·필터링·화면 표시에서 동일한 카테고리 기준을 쓴다.

| 원본 | 통합 카테고리 |
| --- | --- |
| 기업마당 금융 / K-Startup 융자·사업화 | 자금 |
| 기업마당 기술 / K-Startup 기술개발(R&D) | R&D·기술 |
| 기업마당 수출·내수 / K-Startup 글로벌(판로·해외진출) | 수출·글로벌 |
| 기업마당 인력 / K-Startup 인력 | 인력 |
| K-Startup 시설·공간·보육 | 시설·공간·보육 |
| 기업마당 경영(컨설팅류) / K-Startup 멘토링·컨설팅·교육(컨설팅류) | 멘토링·컨설팅 |
| K-Startup 행사·네트워크 + 멘토링·컨설팅·교육(교육류) | 교육·행사·네트워킹 |
| 기업마당 기타·경영(잔여) | 기타 |

## 적용 원칙

- 공고를 수집·정규화하는 시점에 원본 카테고리를 위 표의 통합 카테고리로 변환해 저장한다. 원본 카테고리는 참고용으로만 별도 보관하고, 필터링·표시에는 통합 카테고리만 사용한다.
- 두 원본 모두에 없는 새 카테고리가 생기면, 가장 가까운 통합 카테고리에 매핑하거나 표에 새 행을 추가한 뒤 "기타"로 흡수하지 않는지 먼저 검토한다.
- 통합 카테고리 8종(자금 / R&D·기술 / 수출·글로벌 / 인력 / 시설·공간·보육 / 멘토링·컨설팅 / 교육·행사·네트워킹 / 기타)은 프론트엔드 필터·기업 프로필 분야 선택 등 카테고리를 노출하는 모든 화면에서 동일하게 사용한다.
